# Portal scrapenvases.com — material del rediseño

Carpeta con toda la documentación para reposicionar **scrapenvases.com** como el
**escaparate del CORE** de la RAP de envases comerciales e industriales
(RD 1055/2022).

Concepto: pasar de una web informativa sobre dos herramientas a un portal del
sector que presenta un ecosistema que **ya existe** —**PROBATUS** (homologación),
**INPROGEST** (control documental) y **SCRAPP** (documentos e incentivos)— y que
cubre las necesidades de SCRAPs, gestores y poseedores. **Tono: neutro de portal.**

> Índice visual: abrir **`indice-portal.html`** en el navegador.

## Mapeo del CORE (validado)
- **PROBATUS** → homologación de proveedores/gestores → **probatus.es**
- **INPROGEST** → control documental de los servicios → **inprogest.com**
- **SCRAPP** → documentos e incentivos del poseedor (trazabilidad) → **scrapp.es**
